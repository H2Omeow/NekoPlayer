# NekoPlayer v1.4.7

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

修掉全屏后跳回首页的问题，补上赞赏前的付款页与驳回原因，让 3.25 / 32.5 / 7.99 这些数字在任何出现的位置都能点出说明，并补齐新功能的多语言文案。

## 修复

### 视频

- 点全屏不再「横一下就回首页」：补齐 Activity 的 `configChanges`，转屏不重建界面；同时把页面栈存进 `rememberSaveable`，即使被系统重建也能回到原来那一页
- 全屏退出后仍保留原视频，不会因为旋转丢失播放状态

### 云存储

- 「去赞赏」不再直接弹文件选择器：先展示付款页，列出微信、支付宝收款码与订单号，付款后再点「我已完成支付，上传凭证」
- 订单被驳回时显示管理员填写的原因；未填原因时提示可联系管理员
- 额度页、额度表、赞赏介绍里凡出现 3.25 / 32.5 / 7.99 的位置都能连点触发说明，不再只有顶部那一处
- 说明正文改为原版语录

### 多语言

- 云存储、视频详情、播放器、登录、设置等新增界面补齐简体中文、繁体中文、英文、日文四套文案（新增约 200 条）
- 播放量单位按语言区分：英文用 K / M / B，中日文用 万 / 亿

## 升级说明

- 覆盖安装即可，账号与本地设置保留
- 已有订单状态与凭证不受影响
