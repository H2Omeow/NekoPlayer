# NekoPlayer 1.2.4

修复窄 / 矮窗口打开播放页时的崩溃，并在「发现」页加入热门搜索和输入建议。

## 桌面端

- 修复窗口较矮时打开全屏播放页报 `Invalid argument(s): 120.0`、页面构建失败的问题；封面尺寸现在会同时限制在窗口可用高度和最小尺寸之间。
- 「发现」搜索框为空时显示当前音源的热门搜索，点击直接搜索。
- 输入关键词后自动显示搜索建议，包含歌曲、歌手和专辑；点击建议即可搜索。
- 切换音源会自动刷新热门搜索和建议；脚本音源或不支持建议接口的音源会自动隐藏该区域，不影响正常搜索。
- 新增「热门搜索」「搜索建议」的繁体中文、英文和日文翻译。

## Android

- 版本号同步为 1.2.4，功能与 1.2.3 相同。

## 安装

- Android：下载 APK 覆盖安装，保持原签名；包含 ARMv7、ARM64、x86、x64。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`，无需另装 Java。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。DEB / RPM 已声明 `libgtk-layer-shell0` / `gtk-layer-shell` 依赖；使用 tar.gz 时请自行安装，否则 Wayland 下悬浮歌词无法保存位置。

下载后可通过 `SHA256SUMS` 校验文件完整性。
