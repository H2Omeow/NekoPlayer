# NekoPlayer 1.2.2

Android 新增播放 / 暂停淡入淡出；桌面端新增性能档位与动态歌词画质控制，修复 4K / 高显示缩放下的界面卡顿和内嵌动态歌词空白。

## Android

- 新增播放 / 暂停淡入淡出，可在「设置 → 播放」中开关并调整时长（0.05–2 秒）。
- 界面按钮、通知栏、耳机按键和蓝牙控制均使用同一套淡入淡出逻辑。
- 淡出结束后保持静音直到下次播放，避免暂停瞬间漏出缓冲音频。

## 桌面端

- 新增「设置 → 性能 → 性能与动态歌词」：自动检测物理分辨率、显示缩放、刷新率和显卡，并选择界面性能与动态歌词画质。
- 动态歌词新增高清、均衡、省电、极简和自动档；自定义档支持 25%–150% 渲染比例、30–240 FPS 或「无上限」，以及关闭滤镜和背景动效。
- 4K / 高 DPI 下自动限制模糊半径并跳过页面转场；壁纸、播放页背景和推荐卡片模糊按物理像素封顶，降低 GPU 负载与大幅切换界面时的崩溃风险。
- 修复 Windows 300% 缩放下内嵌动态歌词加载后空白的问题：WebView2 使用显式物理像素边界并固定 rasterization scale。
- Windows 通过 DXGI 读取显卡信息，辅助自动选择性能档位。

## 安装

- Android：下载 APK 覆盖安装，保持原签名；包含 ARMv7、ARM64、x86、x64。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`，无需另装 Java。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。DEB / RPM 已声明 `libgtk-layer-shell0` / `gtk-layer-shell` 依赖；使用 tar.gz 时请自行安装，否则 Wayland 下悬浮歌词无法保存位置。

下载后可通过 `SHA256SUMS` 校验文件完整性。
