# NekoPlayer v1.4.2

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

修复 1.4.1 中绑定弹窗在窄屏下布局溢出，以及绑定接口读不到 JSON 请求体的问题。

## 修复

### 绑定弹窗

- 三个模式按钮改为等宽布局，窄屏不再把「手机密码」挤成竖排。
- 输入区改为单列：手机号、验证码、密码分别使用对应键盘类型，密码输入启用掩码。
- 提交前校验 11 位手机号，格式不合法时本地提示，不发起请求。

### 服务端

- 账户中心仅注册了 `express.urlencoded`，未注册 `express.json`，导致客户端发送的 JSON 请求体为空、手机号为空，接口统一返回「手机号格式不正确」。已补充 `express.json`。

## 升级说明

- 覆盖安装即可；绑定失败的账号可直接重试。

## 产物

Android APK、Windows x64/ARM64 安装包、Linux x64/ARM64 的 DEB/RPM/tar.gz，以及 `SHA256SUMS`。
