# NekoPlayer v1.4.2

这一版把「云存储」和「社区」真正接了起来：文件能上传、能分享、能看额度，账号能绑森空岛，后台有一套完整的审核面板。

## 云存储

- **上传**：任意文件上传到对象存储（雨云 ROS），超过 5MB 自动分片、断点续传、失败自动中止会话，不上传服务器本机。
- **额度**：免费用户 3.25G 存储 / 3.25G 月流量 / 50 份文件；视频 ≤50MB、图片 ≤5MB、音乐 ≤25MB、自定义文件 ≤1G（占 5 份）。
- **赞赏用户**：32.5G 存储 / 50G 月流量，不限文件份数、不限单文件大小，且文件永不清理。
- **半年未登录清理**：免费用户超过 180 天未登录会清理上传的文件（歌单、收藏、播放记录不受影响），清理前 7 天会在「消息」里提醒。
- **分享**：应用内分享（下载扣分享者一半流量）或直链分享（免登录下载，扣全额流量），可选 1/7/30 天有效期；分享者流量用完时链接会暂时不可用。
- **额度与规则**页：把额度、计费口径、清理规则、服务端限制和实时用量都写在客户端里，不藏在后台。

## 赞赏与人工审核

- 赞赏档位：7.99/月（32.5G + 50G）、64.8/月（200G + 100G，限量 2 个名额）。
- 不做支付网关：客户端下单后展示收款码，付款后上传凭证截图，管理员在后台人工核对并开通。
- 订单状态：待审核 / 已开通 / 已驳回，驳回会显示理由。

## 森空岛绑定

- 云存储相关功能需要先绑定森空岛账号（扫码授权，只取用户 ID，不读取游戏数据）。
- 未绑定时接口返回 `needSkland`，客户端会直接弹出绑定引导，而不是一个看不懂的错误。

## 社区

- 好友、关注/粉丝、动态流、私信的接口已就位，桌面与安卓都复用同一套本站账号体系。
- **在线状态**：私信列表与聊天头部会显示好友是否在线（70 秒内有活动即在线，SSE 连接每 25 秒保活）。
- **文件分享到好友**：生成分享链接后可以直接选一位好友发送，链接会以私信形式送达。

## 管理后台

- `/admin` 独立面板：总览、用户、订单、套餐额度、文件、审计、系统、收款码。
- 未登录时停在登录页，可直接跳转账户中心登录；也支持面板密钥（写入 httpOnly cookie）。
- 手机端适配：表格自动变卡片，页签可横向滑动，支持 `/admin#users` 这类深链接。
- 所有写操作都会写审计日志（操作前后 JSON + IP + UA）。

## 修复与调整

- 修正对象存储分片上传的签名方式（预签名分片 URL + 服务端 header 签名完成），大文件不再报 `SignatureDoesNotMatch`。
- 修正 HeadObject 使用预签名导致的 404。
- 管理面板的接口响应加 `no-store` 与缓存穿透参数，避免旧密钥的 304 缓存把面板卡在「无管理权限」。

## 验证

- Android：`:app:compileDebugKotlin`、`:app:assembleDebug` 通过；新增单元测试与联网冒烟测试通过。
- 服务端：单次直传、分片上传、分享直链、流量计费、180 天清理与提前提醒、森空岛绑定拦截均已用真实请求跑通。
- 桌面端：需要 Flutter SDK 构建，本机未安装，改由 CI 的 `flutter analyze` 与 `flutter test` 把关。

## 修复

- 修复森空岛绑定弹窗在窄屏上三种登录方式按钮溢出的问题；
- 服务端补充 JSON 请求体解析，修复手机号被判定为格式不正确的问题。

## 森空岛账号绑定新增登录方式

- 除 App 扫码外，新增「手机号 + 短信验证码」「手机号 + 密码」两种绑定方式；
- 密码只在内存中用于换取鹰角凭证，服务器不保存；
- 验证码发送有 60 秒本地节流，并透传鹰角的频率限制提示。
