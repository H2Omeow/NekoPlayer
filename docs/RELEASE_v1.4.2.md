# NekoPlayer 1.4.2

修 1.4.1 里绑定弹窗在窄屏上被挤爆、以及绑定请求收不到请求体的问题。

## 绑定弹窗

- 三个模式 chip 改成等宽（`weight(1f)`），不再把「手机密码」挤成竖排。
- 输入框改为单列布局，手机号 / 验证码 / 密码都有对应的键盘类型与密码掩码。
- 本地先校验 11 位手机号，格式不对直接提示，不发请求。

## 服务端

- 账户中心原先只挂了 `express.urlencoded`，没挂 `express.json`，导致客户端发的 JSON 请求体是空的、手机号为空、一律返回「手机号格式不正确」。已补上 `express.json`。
