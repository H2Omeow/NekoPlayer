# NekoPlayer v1.5.0

2026-11-28 发布 · Android / Windows / Linux

## Android 端更新

- **性能与架构**：拆分高频播放进度状态流，消除播放时每秒多次触发全应用 UI 重组带来的卡顿与耗电；修复队列跨音源歌曲判重与排序崩溃问题。
- **视觉与沉浸式体验**：启用全屏 Edge-to-Edge 透明状态栏/导航栏；统一全站弹窗、底栏与下拉菜单实体底色，解决全局壁纸模式下透底问题；视频、社区与云存储页面统一设计规范并支持壁纸透出。
- **全屏播放器与音效**：竖屏顶栏新增「封面 / 歌词」切换胶囊与封面下实时歌词预览，支持点击歌词行跳转进度与长句逐字歌词自动换行；重写 10 段均衡器为独立竖向推子，设置首页补齐状态摘要并收纳语言与音质选择。
- **交互与功能修复**：补齐所有二级页面系统返回键导航；重做歌曲评论与 MV 底栏并修复插件音源评论错位；修复视频左滑亮度手势、清晰度切换、自动连播、弹幕输入框高度及首页双列网格对齐；补齐多语言文案。

## 安装

- Android 用户可直接覆盖安装，保留原有设置和数据。
- Windows 和 Linux 用户可按系统与架构选择对应安装包。发布页提供 SHA-256 校验清单。
