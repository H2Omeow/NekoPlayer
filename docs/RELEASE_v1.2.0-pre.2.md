# NekoPlayer 1.2.0-pre.2

第二个 1.2.0 预发布版，修复 pre.1 测试中发现的问题。

## 平台曲库

- 修复酷狗账号歌单中的歌曲没有名称、歌手和封面的问题；歌词现在能正常加载和滚动。
- Android 端的酷狗歌单同步应用同样的修复。

## 桌面端

- 修复切换页面时动画背景变成纯黑、遮住壁纸的问题。
- 面板不透明度范围放宽到 20%–100%，步进改为 1%。
- 桌面歌词新增可选内容：歌名、进度条、上一首 / 播放暂停 / 下一首；全部可在「设置 → 桌面歌词与系统控制」中单独开关，并会保存。

## 播放

- 关闭内置 mpv 的磁盘缓存，修复部分系统上反复出现的「Failed to create file cache」。
- 网络超时从 5 秒放宽到 30 秒，改善网络较慢时无法开始播放的问题。
- 关闭 mpv 对 yt-dlp 的试探，避免播放失败时多余的错误和延迟。

## 安装

- Android：下载 APK 覆盖安装，保持原签名。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。

下载后可通过 `SHA256SUMS` 校验文件完整性。
