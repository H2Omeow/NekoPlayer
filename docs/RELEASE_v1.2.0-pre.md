# NekoPlayer 1.2.0-pre

预发布版，用于正式 1.2.0 之前的测试。

- 云端同步改版：新增独立的同步页面，可分别选择收藏、历史、歌单和音乐平台登录，选择上传、拉取或合并，查看本机与云端的更新时间，并按项目开启自动同步；两端都改过时由你选择方向。
- Android 与桌面重新设计界面，统一间距、分组和设置页结构。
- 修复 Android 动态歌词引擎无法渲染的问题。
- 桌面：歌词引擎内置在应用窗口中；新增崩溃日志与诊断页面；从云端拉取 Cookie 后正确显示登录状态；修复无法获取壁纸的问题。
- Linux：兼容 libmpv v2（Arch Linux 等新发行版）。

## 安装

- Android：下载 APK 覆盖安装，保持原签名。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`。安装包未配置代码签名，系统可能提示未知发布者。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。

## 注意

云端同步使用新的数据格式，建议所有设备都升级到本版本后再开启自动同步。同步「音乐平台登录」会上传网易云 / 酷狗 Cookie，只在信任的设备上开启。

下载后可通过 `SHA256SUMS` 校验文件完整性。
