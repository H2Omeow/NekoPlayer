# NekoPlayer v1.4.1

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

森空岛绑定不再只支持扫码：新增手机验证码与手机密码两种方式，双端同步。

## 新增

### 森空岛绑定

- 手机验证码：60 秒节流发送，服务端只做转发，验证码不落库。
- 手机密码：密码仅用于换取鹰角凭证，不写入任何存储。
- 绑定弹窗改为扫码 / 验证码 / 密码三种模式切换，绑定成功后立即刷新云存储权限。

## 修复

- 账户中心接口支持 `Authorization: Bearer`，Android 与桌面端不再依赖浏览器 Cookie。
- 森空岛账号已绑定其他账户时返回 409，并在客户端提示冲突。

## 桌面端

- 云存储页同步支持验证码与密码绑定，倒计时与服务端节流一致。

## 升级说明

- 覆盖安装即可。
- 已绑定的账号无需重新绑定。

## 产物

Android APK、Windows x64/ARM64 安装包、Linux x64/ARM64 的 DEB/RPM/tar.gz，以及 `SHA256SUMS`。
