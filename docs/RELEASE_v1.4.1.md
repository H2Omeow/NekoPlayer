# NekoPlayer 1.4.1

森空岛绑定不再只有扫码：手机号收验证码、手机号加密码都能完成绑定，双端同步。

## 森空岛登录

- 新增「手机验证码」：60 秒节流发送，服务端只做转发，验证码不落库。
- 新增「手机密码」：密码仅用于换取鹰角 token，不写入任何存储。
- 绑定弹窗改成三个模式切换（扫码 / 验证码 / 密码），绑定成功后立即刷新云存储权限。

## 账户中心

- 鹰角相关接口支持 `Authorization: Bearer`，安卓与桌面不再依赖浏览器 Cookie。
- 绑定冲突（该森空岛账号已绑定其他账户）返回明确的 409 提示。

## 桌面端

- 云存储页同步支持验证码与密码两种绑定方式，60 秒倒计时与安卓一致。
