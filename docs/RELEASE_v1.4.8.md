# NekoPlayer v1.4.8

发布：2026-11-20　平台：Android / Windows / Linux

## 概要

新增 32.5 元/月的「进阶」档位，赞赏页现在会列出每一档的实际容量；同时修掉额度说明写死容量的问题，服务端与后台不需要发版即可调档。

## 新增

- 云存储新增「进阶」档：32.5 元/月，80G 存储 + 100G 流量，不限文件份数与单文件大小
- 赞赏页的档位卡片显示该档的存储与流量，文案不再写死某一档的数字
- README 补充三档赞赏的容量说明

## 修复

- `/pricing` 之前的响应会被反向代理缓存，改档后客户端仍看到旧数据；现在价格、订单、奖励图等接口全部绕过缓存
- Android 赞赏页的说明文字改为「不同档位的容量见下方」，避免与后台调整后的数值不一致

## 升级说明

- 服务端只需重启 `SuperPlayer-Web`，档位数据在管理后台「套餐额度」页可以直接改
- 已有赞赏用户的权益不变；新档位需要管理员在后台确认容量后由用户下单、人工审核开通

- Windows：`NekoPlayer-v1.4.8-windows-x64-setup.exe`、`NekoPlayer-v1.4.8-windows-arm64-setup.exe`
- Linux：x64 / arm64 的 `.deb`、`.rpm`、`.tar.gz`
- `SHA256SUMS`
