# NekoPlayer v1.4.4

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

本次修复 B 站视频在 Android 上全部清晰度均无法播放的问题，云存储入口改为全屏页面，并为森空岛短信登录增加网页兜底。

## 修复

### 视频播放

- 媒体请求恢复初始 `Range: bytes=0-`。B 站 CDN 对不带 `Range` 的请求返回 567，此前首发请求没有该头，导致所有清晰度均失败。
- 媒体请求改用桌面浏览器 User-Agent。使用移动端 UA 时 CDN 返回 403。
- 修复后 360P 至 720P 均可正常直连播放；1080P 仍需登录 B 站账号。

### 云存储入口

- 从视频「我的」页面进入云存储改为全屏对话框，不再被底部迷你播放器与导航栏遮挡。

### 森空岛

- 新增「网页登录」兜底：在 App 内打开鹰角官方登录页完成人机验证，登录后自动获取凭证并完成绑定，无需手动复制 token。
- 短信验证码改用登录用途（此前误用换绑类型，验证码会被判定为错误）。

### 显示

- 额度数值精确到两位小数并去除尾零，3.25GB 不再显示为 3.3GB；管理后台与桌面端同步修正。
- 额度数字区域增加隐藏点击交互，不影响任何功能。

## 升级说明

- 覆盖安装即可。
- 若此前在 App 内绑定森空岛失败，更新后可直接重试。

## 产物

Android APK、Windows x64/ARM64 安装包、Linux x64/ARM64 的 DEB/RPM/tar.gz，以及 `SHA256SUMS`。
