# NekoPlayer 1.4.4

森空岛短信被鹰角风控要求人机验证时，可以在 App 内的网页里完成登录并自动绑定；额度数字改为精确显示。

## 森空岛

- 新增「网页登录」兜底：打开鹰角官方登录页（含人机验证），登录成功后自动取出凭证并完成绑定，不需要用户手动复制 token。
- 短信验证码修正为登录用途（之前用了换绑类型，导致验证码一律被判错误）。

## 云存储

- 额度显示精确到两位小数：3.25G 不再显示成 3.3G，32.5G 不再显示成 32.5G 的近似值；管理后台与桌面端同步修正。
- 额度数字上加了隐藏点击彩蛋（点满若干次会出现说明），不影响任何功能。

## 视频

- 同 1.4.3：播放失败自动重取直链并逐级降清晰度、请求带 Cookie、新增「我的」页面、播放页留白调整、UP 主关注按钮。
