# NekoPlayer 1.2.0-pre.3

新增自定义字体。

## 字体

- 桌面端：在「设置 → 主题与背景 → 字体」选择本地 TTF / OTF 文件，应用到整个界面；支持恢复默认字体。
- Android：在「设置 → 主题与背景 → 字体」选择字体，应用到界面和悬浮歌词；字体文件会复制到应用目录，原文件删除后仍可使用，也可一键恢复默认。
- 字体超过 64MB 或不是 TTF / OTF 时会拒绝并保留原来的字体。字体缺少的中文字符会回退到内置 / 系统字体。
- 桌面端原生桌面歌词窗口暂不跟随自定义字体。

## 安装

- Android：下载 APK 覆盖安装，保持原签名。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。

下载后可通过 `SHA256SUMS` 校验文件完整性。
