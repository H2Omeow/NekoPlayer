# NekoPlayer 1.2.6

新增独立的「视频」模块：B 站搜索、播放页、弹幕、扫码登录，并补齐大量可自定义项。这是本轮视频重构的第一个可用版本。

## 新增：视频 Tab

- 双端导航新增「视频」入口（Android 在「音乐」与「社区」之间，桌面在左侧栏「发现」下方）。
- 独立的视频首页：搜索框、推荐 / 热门 / 最多播放筛选、双列封面墙、无限滚动加载。
- 独立的播放页：不再复用 MV 弹窗——16:9 播放器、标题与 UP 主信息、相关推荐、播放进度记忆、桌面端右侧相关推荐栏与全屏（剧场）模式。

## B 站接入（Android 直连，不经 JS 插件）

- 新增 `data/bilibili/`：wbi 签名（`w_rid`）、手写 protobuf 弹幕解析、登录态（Cookie）与请求封装。
- 搜索、视频详情、播放地址（`playurl`，`fnval=1` 取 mp4 直链）、相关推荐、热门、评论、热搜词、点赞 / 投币 / 收藏。
- 弹幕按 6 分钟分段拉取（最多 60 段），统一排序后在渲染层做同屏裁剪。

## 弹幕

- 自绘弹幕层（Compose Canvas / Flutter CustomPainter）：滚动、顶部、底部三种模式，按播放进度驱动，暂停与拖动进度条时位置同步。
- 可自定义：显示开关、不透明度、字号、速度、显示区域（1/4–全屏）、同屏密度、加粗、描边粗细、阴影、彩色弹幕、屏蔽词、合并重复。
- 发送弹幕（需登录）、弹幕开关按钮、每部视频的设置即时生效。

## B 站登录（三种方式）

- **App 扫码**：App 内离线生成二维码 → 轮询 → 手机确认后自动写入 Cookie 并刷新昵称头像。
- **应用内网页登录**（Android）：在登录页内嵌 WebView 打开 B 站登录页，支持账号密码 / 短信验证码；登录完成后自动读取 Cookie 并回到 App，不需要手动复制。
- **Cookie 导入**：可整串粘贴，也可只填 SESSDATA + bili_jct（+ 可选 DedeUserID），并支持一键从剪贴板读取；桌面端为「扫码 + Cookie 粘贴 + 从剪贴板粘贴」，只贴 SESSDATA 的值也会自动补键名。
- Cookie 只保存在本机应用私有目录；退出登录即清除。
- 游客可看 720P，登录后按可用的最高清晰度播放。

## 播放器

- 自定义控制条：播放 / 暂停、进度条、时间、弹幕开关、清晰度、倍速、全屏。
- 手势与快捷键：单击显隐控制条、双击左右 ±10s、长按倍速（Android）；空格播放暂停、←/→ 10s、F 全屏、D 弹幕开关、Esc 退出全屏（桌面）。
- 记住播放进度，回到视频页可从上次位置继续。
- 修复 B 站视频播放的请求头（`Referer` / `Origin` / `Range` / 浏览器 UA），沿用 v1.2.5 的音频修复经验。

## 设置

- 弹幕设置与播放器设置分别可恢复默认。
- 视频设置、播放设置与观看进度独立存储，不影响音乐模块的设置。

## 验证

- Android：`./gradlew :app:compileDebugKotlin`、`:app:assembleDebug` 通过；新增 19 个 JVM 单测（wbi 签名、弹幕 protobuf、弹幕过滤、时长/清晰度格式化）全部通过。
- 联网冒烟测试（`BILI_LIVE=1` 时运行）：真实搜索、取详情、取 720P 直链、拉取弹幕、生成登录二维码均成功。
