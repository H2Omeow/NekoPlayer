# NekoPlayer v1.4.0

发布：2026-11-18　平台：Android / Windows / Linux

## 概要

本版新增云存储模块，并补齐社区的关系链能力：文件可以上传、分享、跨端查看，会话与主页显示在线状态，文件可直接发送给好友。云存储要求先绑定森空岛账号。

## 新增

### 云存储

- 文件直传 S3 兼容对象存储，私有桶 + 服务端预签名，服务器不保存文件本体。
- 超过 5MB 自动分片（5MB 一片），支持失败中止；上传完成后由服务端 HEAD 校验大小并写入记录。
- 文件列表、下载、删除（软删除并回冲用量）、剩余额度在客户端可见。

### 额度

- 免费：3.25GB 存储、每月 3.25GB 流量、50 份文件；视频 ≤50MB、图片 ≤5MB、音乐 ≤25MB、自定义文件 ≤1GB 且占 5 份。
- 赞赏：32.5GB 存储、每月 50GB 流量，不限份数与单文件大小，文件不参与过期清理。
- 分享与下载均扣除分享者流量，应用内下载按一半计。
- 免费用户连续 180 天未登录会清理上传文件（歌单、收藏、播放记录不受影响），清理前 7 天发送站内信。

### 分享

- 应用内分享：下载经由服务端，扣除一半流量。
- 直链分享：免登录 302 跳转到预签名地址，扣除全额流量，有效期 1/7/30 天。
- 新增 `s/{token}` 分享落地页；分享者流量用尽时链接暂时不可用。

### 社区

- 会话列表与聊天页显示在线状态（15 秒心跳，70 秒窗口）。
- 文件列表支持分享给好友，链接直接发送到站内私信。

### 赞赏与人工审核

- 档位：7.99/月（32.5GB + 50GB）、64.8/月（200GB + 100GB，限量 2 个）。
- 不接入支付网关：下单后展示收款码，上传凭证，由管理员在后台核对后开通；支持驳回并填写理由。

### 森空岛

- 云存储需要先绑定森空岛账号，本版提供 App 扫码绑定；仅获取用户 ID 与凭证，不读取游戏数据。

### 管理后台

- 新增 `/admin`：总览、用户、订单、套餐额度、文件、审计、系统、收款码八个页签，支持移动端。
- 所有写操作记录审计日志（操作前后数据、IP、User-Agent）；未登录停留在登录页，可跳转账户中心登录。

## 升级说明

- 覆盖安装即可；账号、播放记录与本地数据保持不变。
- 云存储需要账户中心版本同步更新后使用。

## 产物

Android APK、Windows x64/ARM64 安装包、Linux x64/ARM64 的 DEB/RPM/tar.gz，以及 `SHA256SUMS`。
