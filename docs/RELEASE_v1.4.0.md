# NekoPlayer 1.4.0

新增「云存储」：文件传到自己买的对象存储，不经过服务器中转；同时把社区的关系链真正用起来（在线状态、把文件分享给好友），并加入森空岛绑定作为云存储的前置条件。

## 云存储

- 文件直传雨云对象存储（S3 兼容）：客户端向服务端要预签名地址，文件从手机 / 电脑直接 PUT 上去，服务器不落盘。
- 超过 5MB 自动分片（5MB 一片），失败可中止并重来；上传完成由服务端 HEAD 校验大小。
- 文件列表、下载、删除（软删除并回冲用量）、剩余额度都在客户端可见。

## 额度

- 免费：3.25G 存储、每月 3.25G 流量、50 份文件；视频 ≤50MB、图片 ≤5MB、音乐 ≤25MB、自定义文件 ≤1G 且占 5 份。
- 赞赏：32.5G 存储、每月 50G 流量，不限份数与单文件大小，且文件永不清理。
- 分享和下载都扣**分享者**的流量，应用内下载减半。
- 免费用户连续 180 天未登录会清理上传的文件（歌单、收藏、播放记录不受影响），清理前 7 天站内信提醒。

## 分享

- 应用内分享：下载走服务端，扣分享者一半流量。
- 直链分享：免登录 302 到预签名地址，扣全额流量，可选 1/7/30 天有效期。
- 新增 `s/{token}` 分享落地页；分享者流量用完时链接暂时不可用。

## 社区

- 会话列表与聊天页显示在线绿点（15 秒心跳，70 秒窗口）。
- 文件列表可以「分享给好友」，链接直接发进站内私信。

## 赞赏与人工审核

- 档位：7.99/月（32.5G + 50G）、64.8/月（200G + 100G，限量 2 个）。
- 不做支付网关：下单后展示收款码，上传凭证，管理员在后台人工核对后开通；支持驳回并附理由。

## 森空岛

- 云存储需要先绑定森空岛账号，绑定方式为 App 扫码；只取用户 ID 与凭证，不读取游戏数据。

## 管理后台

- 新增 `/admin`：总览、用户、订单、套餐额度、文件、审计、系统、收款码八个页签，支持手机端。
- 所有写操作记录到审计日志；未登录停在登录页，可跳账户中心登录。
