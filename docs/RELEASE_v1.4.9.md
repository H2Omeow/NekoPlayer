# NekoPlayer v1.4.9

发布：2026-11-21　平台：Android / Windows / Linux

## 概要

桌面端的视频模块补齐到与 Android 同一套能力：分区首页、独立搜索页、播放页的点赞 / 投币 / 收藏 / UP 主关注、简介与评论切换、弹幕发送、「我的」页与观看历史。同时把所有新增文案接入 i18n。

## 新增

- 桌面视频首页改为分区：推荐、音乐现场、MV、知识、关注；顶栏搜索打开独立搜索页
- 新增「继续观看」横滑区，播放进度会记录到本地，重启后仍在
- 新增搜索页：综合 / 最多播放 / 最新发布 / 最多弹幕排序、热搜词、滚动加载
- 播放页补齐互动：点赞、投币、收藏、分享链接、UP 主关注 / 已关注
- 播放页信息区改为「简介 / 评论」两个 Tab，评论支持分页加载
- 简介下方新增弹幕输入框，发送后立即出现在画面上
- 新增「我的」页：账号卡、退出登录确认、观看历史（可单条删除、可清空）
- 新增文案全部补齐简体中文 / 繁体中文 / 英文 / 日文

## 修复

- 播放页信息区原先只有标题和简介，窗口较窄时内容被裁切
- 首页搜索框改为只读入口，避免在首页里出现两套搜索结果

## 升级说明

- 桌面端无需迁移，观看记录保存在本机的 `video_watch_v1`
- 点赞、投币、收藏、关注、发弹幕都需要先在「我的」页登录 B 站账号
