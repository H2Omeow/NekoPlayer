# NekoPlayer v1.4.5

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

本次集中在「用起来别扭的地方」：手机竖屏的播放控制条重排、横屏全屏真正沉浸、播放设置面板不再透底、云盘上传与文件操作更稳，另外补上了 B 站 Cookie 有效性和删除操作的确认。

## 修复

### 视频

- 窄屏控制条改为两行：时长和进度条独占一行，弹幕、清晰度、倍速、全屏在第二行，竖屏不再把进度条挤成一条竖线
- 横屏全屏时隐藏底部导航栏与迷你播放器，画面按整屏高度铺满；退出后恢复原方向，不再强制锁竖屏
- 切换相关推荐后清空上一个视频的标题、评论、弹幕和进度，加载失败会显示错误页而不是旧内容
- 换清晰度或重试播放时从当前位置继续，不再跳回片头
- 退出播放器后恢复屏幕常亮标志与系统亮度
- 播放设置、弹幕设置、弹幕输入条与云盘弹窗改用不透明底色，不再透出背后的文字和封面
- 顶部/底部固定弹幕与滚动弹幕分开占轨，避免叠字
- 发送弹幕期间禁用重复提交，失败时区分「未登录」和具体错误
- 返回键按页面栈回退：详情页返回搜索页，不再直接回首页
- 「分享」真正写入剪贴板；「清空观看历史」增加二次确认
- 关闭「记住播放进度」后不再写入历史

### 账号与云存储

- 导入 Cookie 时校验 `SESSDATA` 并请求一次账号信息，乱填或过期会留在登录页提示，不再假登录
- 大文件上传改为流式分片，未知大小的文件先落缓存取真实大小，避免整文件读进内存
- 桌面端分片上传只打开一次文件句柄并在结束时关闭
- 删除文件增加确认框，失败会提示原因
- 分享链接弹窗支持一键复制，分享失败保留弹窗并提示
- 森空岛网页登录弹窗关闭时销毁 WebView，二维码改为后台线程生成

## 升级说明

- 覆盖安装即可，账号与本地设置保留
- 云存储的分享链接与已绑定账号不受影响
