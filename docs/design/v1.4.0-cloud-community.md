## 1 现有后端盘点

**账户中心** `/www/wwwroot/account`（Express，`src/routes/*`，JSON 文件存储 `users.json`）
- 已有：注册/登录、邮箱验证、`thirdPartyBindings`（彩虹聚合登录，支持 QQ/微信等）
- 缺少：森空岛；`config.rainbow.providers` 受套餐限制

**播放服务** `/www/wwwroot/superplayer`（Express + SQLite + `social.mjs`）
- 云同步：`GET /user/data`、`PUT /user/data`、`PATCH /user/data/sections`，分区 `favorites/history/playlists/credentials`，AES 加密落盘 `data/userdata`，带 `expected` 乐观锁
- 社区（已在服务端就绪）：分享 `/social/shares`、用户搜索/主页、关注/粉丝、拉黑、`/social/feed`、私信会话与消息、`/social/preferences`、`/social/unread`、SSE `/social/events`

**对象存储**：雨云 ROS 管理页 `https://app.rainyun.com/apps/ros/list`
- 桶：`nekoplayer-free`、`nekoplayer-sponsor`
- 支持：预签名 URL（最长 24h）、防盗链、IP 白名单、CC 防火墙、自定义域名 + SSL
- 计费：套餐内 500G；超出套餐流量 0.1 元/GB（宁波）

## 2 森空岛登录（已实测）

流程（扫码，无需输入鹰角密码）：
1. `POST https://as.hypergryph.com/general/v1/gen_scan/login`（空 body）
   → `{status:0, data:{scanId, scanUrl:"hypergryph://scan_login?scanId=..."}}`
   - 实测：**不带 dId 也返回 200 + scanId**，无需数美设备指纹
2. 前端把 `scanUrl` 生成二维码，用户用「森空岛 App」扫码
3. `GET https://as.hypergryph.com/general/v1/scan_status?scanId=...`
   - 实测未扫：`{"status":100,"msg":"未扫码"}`
   - 已扫待确认 / 失效 / 确认：按 `msg` 文案区分（“未扫码 / 已扫码待确认 / 已失效 / 取消”），确认时 `status=0` 且 `data.scanCode`
4. `POST https://as.hypergryph.com/user/auth/v1/token_by_scan_code` `{scanCode}` → `data.token`（鹰角 OAuth Token）
5. `POST https://as.hypergryph.com/user/oauth2/v2/grant` `{appCode:"4ca99fa6b56cc2ba", token, type:0}` → `data.code`
6. `POST https://zonai.skland.com/web/v1/user/auth/generate_cred_by_code` `{code, kind:1}` → `data.{cred, token, userId}`
7. 用 `userId` 作为森空岛身份，写入账户中心 `thirdPartyBindings[{type:"skland", uid, nickName, boundAt}]`，签发 SSO Cookie/JWT

实测依据（本机 curl，2026-11-17）：
- `gen_scan/login` → 200，返回 scanId + scanUrl + 可扫码 App 列表（含森空岛 `4ca99fa6b56cc2ba`）
- `scan_status` → 200 `{"msg":"未扫码","status":100}`
- `grant`/`token_by_scan_code` 只做字段格式校验，不要求 dId

风险与对策：
- 属**非公开接口**，可能变动 → 封装成单独模块，失败时降级提示「改用 NekoPlayer 账号密码登录」
- 不做「输入鹰角账号密码」，避免触碰敏感凭据
- 只保存 `cred/token/userId`，不保存手机号密码；解绑可随时清除
- 需在登录页写明「第三方登录，非官方接入」

## 3 存储架构

```
App ──①POST /files/upload-url──▶ superplayer(Express)
       ◀─{fileId, putUrl, headers}          │ 校验登录 + 森空岛绑定 + 配额
App ──②PUT putUrl (直传)────────▶ 雨云 ROS 桶（私有）
App ──③POST /files/complete────▶ superplayer → HEAD 对象校验 → 写 SQLite → 计入配额
App ──④GET /files/:id/download─▶ superplayer → 记账 → 302 到 presigned GET
```

- 桶选择：免费用户 → `nekoplayer-free`，赞赏用户 → `nekoplayer-sponsor`（按账号档位路由，便于分别统计/清理）
- key 规则：`u/{userId}/{yyyyMM}/{fileId}.{ext}`，禁止用户自定义路径
- 类型白名单：图片 jpg/png/webp/gif、音频 mp3/flac/m4a/ogg、视频 mp4/webm、自定义 zip/7z/pdf/txt…
- 上传前服务端校验大小上限；上传后 `complete` 再 HEAD 校验实际大小与 content-type，防伪造
- 防盗链：桶开防盗链 + 只走签名 URL；签名 10 分钟过期；`/files/:id/download` 单文件每日限次（默认 50 次/日/文件）
- AK/SK：`/www/wwwroot/superplayer/.env` 新增 `ROS_ENDPOINT/ROS_AK/ROS_SK/ROS_BUCKET_FREE/ROS_BUCKET_SPONSOR`，不写进仓库、不下发客户端

## 4 配额规则（1.4.0 最终版）

| 项 | 免费 | 赞赏（7.99/月，32.5/半年） |
|---|---|---|
| 文件份数 | 50 份 | 无限制 |
| 单视频 | ≤ 50MB | ≤ 50MB（不占份数） |
| 单图片 | ≤ 5MB | 同左 |
| 单音乐 | ≤ 25MB | 同左 |
| 自定义文件 | 占 **5 份**，单个 ≤ 1G | 不占份数，单个 ≤ 1G（分享） |
| 总存储 | **3.25G** | **32.5G** |
| 月度流量 | **3.25G** | **50G** |
| 分享给好友 | 单文件 < 100MB | 软件内不限大小；>1G 只能分享给好友且限下载 1 次 |
| 流量归属 | 扣**分享者**；软件内分享减半 | 同左 |
| 半年未登录 | 删除其上传文件（歌单/播放记录不受影响，无任何限制） | **赞赏过即永不删除** |

补充定义（需要落库）：
- 按**账号**计量，不按设备
- 「份数」= 现存文件数（含自定义文件按 5 计）；删除后返还
- 「总存储」按对象实际字节累加，删除即减
- 「月度流量」按自然月重置，记录 `month, usedBytes`
- 「半年未登录」= `lastLoginAt` 超过 180 天，且仅对 `tier=free` 生效；清理前 7 天站内信提醒（可选）
- 赞赏状态当前无支付 → 先做 `tier` 字段 + 服务端手动开通接口（`POST /admin/grant-sponsor`，仅管理员 token），UI 显示「赞赏即将上线」

## 11 管理后台与人工复审支付（m01880）

### 11.1 形态
- 入口 `https://player.nekoh2o.top/admin`（同域，nginx 无需改动），静态单页 `admin.html` + `/admin/api/*` JSON 接口
- 鉴权：沿用 `resolveUser()`（账户中心 session 或 Bearer JWT），再叠加 `ADMIN_USER_IDS` 白名单（默认 `f97df5a8-e0ff-4df3-a5d2-3cf30137ba75` = H2O）
- 角色三级：`viewer`（只看）/ `operator`（可审单、改用户档位）/ `super`（可改套餐数值、删文件、看审计）
- 所有写操作落 `audit_log`（admin_id / action / target / before / after / ip / ua / ts），后台可查可导出

### 11.2 数据表（node:sqlite，data/cloud/cloud.sqlite）
- `entitlements(user_id PK, tier, expires_at, first_paid_at, forever_keep, note, updated_at)` tier = free|sponsor(799)|sponsor_pro(648)
- `files(id PK, user_id, object_key, name, size, mime, category, sha256, created_at, last_download_at, downloads, share_token, revoked)`
- `shares(token PK, file_id, owner_id, visibility, max_downloads, downloads, expires_at, created_at, revoked)`
- `orders(id PK, user_id, tier, months, amount, method, receipt_key, status, note, reject_reason, reviewer_id, created_at, reviewed_at)` status = pending|approved|rejected|expired
- `usage(user_id PK, storage_bytes, files_count, traffic_bytes, period_start)`
- `settings(key PK, value TEXT)` — 套餐数值、收款码 key、公告开关、熔断阈值
- `audit_log(id INTEGER PK AUTOINCREMENT, admin_id, action, target, before_json, after_json, ip, ua, ts)`
- `announcements(id, title, body, level, audience, created_at, active)`

### 11.3 页面清单
1. 总览：用户数/文件数/存储/本月流量/待审订单/异常数，近 30 天折线
2. 用户：搜索（id/用户名/邮箱/森空岛 uid）；抽屉显示档位、到期、用量、文件、订单、登录记录；操作：改档位、改到期、重置流量、封禁、发站内信、清空文件
3. 文件：按用户/类型/大小/时间筛选；预签名预览与下载；删除；强制撤销分享
4. 分享：token 列表、访问次数、一键撤销、设置上限
5. 订单：pending 队列置顶，凭证图片预览（预签名 10 分钟）、金额与档位校验、通过/驳回（驳回必填理由）、批量操作
6. 套餐与额度：在线编辑 免费/799/648 的存储、流量、份数、单文件上限、价格、并发名额，保存即生效
7. 公告与文案：站内信群发、180 天清理前 7 天提醒模板
8. 审计：按管理员/动作/时间筛选，before/after JSON diff
9. 系统：ROS 连通性测试、桶用量、签名自检、服务健康、熔断阈值（全站 ≥450G 停上传）
10. 收款设置：上传微信/支付宝收款码到 ROS（`settings.receipt_qr`），App 端直接展示

### 11.4 人工复审支付流程
1. 用户选档（799/648）→ `POST /orders` 生成订单号 `NP20261118-XXXXXX`，返回收款码与转账备注要求
2. 用户转账并上传凭证（≤5MB，jpg/png）→ `POST /orders/:id/receipt` 存 `receipts/{orderId}.{ext}`（私有桶），订单转 `pending`
3. 后台待审队列 → 预览凭证 → 通过：写 `entitlements`（`expires_at += months`，`first_paid_at` 首次记录，`forever_keep=1`）+ 站内信 + 审计；驳回：填理由，用户端可见
4. 防滥用：同用户 pending ≤3，凭证 sha256 去重，金额与档位不符自动标黄，凭证保留 180 天后清理
5. 退款/撤销：管理端可手动置回 free，记审计
