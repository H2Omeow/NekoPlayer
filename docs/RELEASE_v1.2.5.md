# NekoPlayer 1.2.5

修复 B 站音源在音乐模式下无法播放，并为 Android 增加日志与诊断导出，双端加入应用数据导出。

## B 站音源

- 修复 B 站音源在「音乐」模式中无法播放：B 站音频代理曾对不带 `Range` 头的普通请求返回拦截页，而音乐模式使用的音频地址与 MV 的完整视频地址不同。
- 桌面端通过 media_kit / FFmpeg 播放时补充 `Range`、`Referer` 和浏览器 User-Agent；Android 端将同样的请求头合并进 ExoPlayer 的数据源，音乐模式恢复播放。
- 下载 B 站音频时同样携带这些请求头，并根据代理地址中的真实文件类型保存为 `.m4a`，不再误写成 `.mp3`。
- MV 播放和原有其他音源不受影响。

## Android 日志与诊断

- 新增滚动运行日志，记录启动、搜索失败、音源解析失败、播放器错误、下载失败和未捕获异常。
- 设置中新增「数据与备份」页面，可导出诊断信息（应用与系统版本、设备、设置摘要、运行日志和崩溃记录），仍可复制最近一次崩溃日志。
- 日志在写入文件前会脱敏 Cookie、令牌、Authorization 头及地址中的查询参数。

## 应用数据导出（双端）

- Android 与桌面端设置中新增「导出应用数据」，通过系统文件选择器保存为 JSON 备份。
- 包含设置、收藏、播放历史、自定义歌单、播放状态、下载 / 缓存记录和音源订阅信息，便于排查问题或自行留存。
- 不包含网易云 / 酷狗登录凭据、Cookie、插件密钥、插件脚本和音频文件。

## Android

- 版本号同步为 1.2.5，包含上述 B 站播放修复、日志诊断导出与应用数据导出。

## 安装

- Android：下载 APK 覆盖安装，保持原签名；包含 ARMv7、ARM64、x86、x64。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`，无需另装 Java。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。DEB / RPM 已声明 `libgtk-layer-shell0` / `gtk-layer-shell` 依赖；使用 tar.gz 时请自行安装，否则 Wayland 下悬浮歌词无法保存位置。

下载后可通过 `SHA256SUMS` 校验文件完整性。
