# NekoPlayer 1.4.3

修 B 站视频播不出来，以及点头像就退出登录这个低级错误；播放页排版放宽。

## 播放

- 播放失败自动重新获取一次直链（B 站直链有时效，重取等于换签名）。
- 还失败就逐级降清晰度：1080P → 720P → 480P → 360P，最多降三级。
- 媒体请求补上登录后的 Cookie，并去掉手写的 `Range` 头（ExoPlayer 自带，避免重复头）。
- 错误码为 HTTP / 网络类时不再无限重试，避免死循环。

## 视频页

- 新增「我的」页面：账号卡（头像 / 昵称 / UID）、观看历史（续播、清空）、云存储入口、弹幕设置、播放设置。
- 点视频页右上角头像进入「我的」，不再直接退出登录；退出登录移到页面底部并二次确认。
- UP 主卡片：登录后不再显示「已登录」，改为读取关注状态，支持关注 / 取关。
- 播放页留白调整：标题上留白、操作栏等距分布、底部内容留白 148dp，弹幕输入条不再压住迷你播放器。

## 森空岛

- 修正扫码状态判断：102 是「已失效」，之前误判为「已扫码」；有效期与服务端对齐为 200 秒，未识别状态保持等待。
