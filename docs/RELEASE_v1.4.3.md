# NekoPlayer v1.4.3

## 视频页

- **修复 B 站视频播不出来**：播放失败时自动重新获取一次直链，并逐级降低清晰度（1080P → 720P → 480P → 360P）重试；请求带上登录 Cookie，减少 CDN 拦截。
- **新增「我的」页面**：点击视频页右上角头像进入，可以看到账号信息、观看历史（可继续播放、可清空）、云存储入口、弹幕设置、播放设置，退出登录改为在这里二次确认。
- 修正 UP 主卡片：以前登录后显示「已登录」，现在会读取关注状态并支持关注/取关。
- 播放页排版放宽：标题、操作栏、UP 主卡片、简介之间增加留白，底部弹幕输入条不再压住迷你播放器。

## 森空岛

- 修复扫码登录后过早提示「二维码失效」：扫码状态改为按返回文案判断，二维码有效期与服务端一致（200 秒），未识别状态保持等待而不是直接判失效。

## 其他

- 管理面板仍然可用；云端接口无破坏性改动。
