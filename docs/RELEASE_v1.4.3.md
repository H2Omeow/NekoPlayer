# NekoPlayer v1.4.3

发布：2026-11-19　平台：Android / Windows / Linux

## 概要

修复 B 站视频无法播放的问题，新增视频模块的「我的」页面，并调整播放页排版。

## 修复

### 播放

- 播放失败时重新获取直链并重试（直链有时效，重新获取等于换签名）。
- 仍失败则逐级降低清晰度：1080P → 720P → 480P → 360P，最多降三级。
- 媒体请求补充登录后的 Cookie，并移除手写的 `Range` 头，改由播放器管理。
- HTTP 与网络类错误不再无限重试，避免循环。

### 视频页

- 新增「我的」页面：账号卡（头像、昵称、UID）、观看历史（续播、清空）、云存储入口、弹幕设置、播放设置。
- 点击视频页右上角头像进入「我的」，不再直接退出登录；退出登录移至页面底部并二次确认。
- UP 主卡片读取关注状态，支持关注与取关。
- 播放页留白调整：标题上留白、操作栏等距分布、底部预留 148dp，弹幕输入条不再遮挡迷你播放器。

### 森空岛

- 修正扫码状态判断：102 为已失效，此前误判为已扫码；二维码有效期与服务端对齐为 200 秒，未识别状态保持等待。

## 升级说明

- 覆盖安装即可。

## 产物

Android APK、Windows x64/ARM64 安装包、Linux x64/ARM64 的 DEB/RPM/tar.gz，以及 `SHA256SUMS`。
