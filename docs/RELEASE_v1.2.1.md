# NekoPlayer 1.2.1

修复桌面端悬浮歌词与任务栏图标问题，修复网页社区登录状态，并解决 Android 冷启动偶发闪退。桌面端新增实际音质显示、可自定义托盘菜单、播放淡入淡出。

## 桌面端

- 悬浮歌词窗口会记住上次拖动后的位置，重启后恢复；Windows、X11 与 Wayland（gtk-layer-shell）均支持。
- Wayland 下悬浮歌词改为透明覆盖层，不再显示普通窗口边框或纯色背景；首次开启时水平居中显示，可拖动定位。
- Linux 任务栏/程序坞图标与桌面启动器使用一致的 application ID，并随安装包提供图标；Windows 设置 AppUserModelID，改善任务栏图标与固定项识别。
- 播放栏与全屏播放器显示当前歌曲实际解析到的音质；本地文件显示容器格式。
- 托盘菜单可分别开关「显示播放器」「播放控制」「桌面歌词」和「音量」子菜单；音量可快速选择 0% / 25% / 50% / 75% / 100%。
- 新增播放 / 暂停淡入淡出，可在「设置 → 播放」中开关并调整时长（0.05–2 秒）。

## Android

- 修复冷启动偶发闪退：网络层初始化与界面初始化之间存在竞争，部分启动会访问尚未初始化的客户端；现已恢复同步初始化。
- 播放服务连接失败时自动重试，不再因 `MediaController` 连接异常直接退出应用。
- 缓存数据库损坏、凭据读取失败、社区前台服务被系统限制时均会降级处理，不再阻止应用启动。
- 「设置 → 后台播放 → 故障诊断」可复制最近一次异常退出日志，便于反馈问题。

## 网页

- 修复网页版登录后进入社区仍显示「请登录」：登录状态回调现在会触发社区界面刷新。

## 安装

- Android：下载 APK 覆盖安装，保持原签名；包含 ARMv7、ARM64、x86、x64。
- Windows：按架构选择 `windows-x64-setup.exe` 或 `windows-arm64-setup.exe`，无需另装 Java。
- Linux：选择对应架构的 DEB / RPM，或解压 tar.gz 运行 `NekoPlayer`。DEB / RPM 已声明 `libgtk-layer-shell0` / `gtk-layer-shell` 依赖；使用 tar.gz 时请自行安装，否则 Wayland 下悬浮歌词无法保存位置。

下载后可通过 `SHA256SUMS` 校验文件完整性。
